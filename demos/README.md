# Demos anteriores

Versiones de demostración con datos de ejemplo, **sin servidor**. Se conservan como referencia del diseño original;
la aplicación real es `../mobile_app` (Flutter) con la API `../server`.

| Carpeta | Qué es | Cómo abrirla |
| --- | --- | --- |
| `web-react/` | Primer prototipo web (React + Vite) | `cd demos/web-react && npm install && npm run dev` |
| `flutter-local/` | Port a Flutter con datos guardados en el teléfono | `cd demos/flutter-local && flutter pub get && flutter run` |
